# Dreame_L10S_ultra_voicepack
# Pack Vocain Français Amplifié pour Dreame (Valetudo)

Pack de voix en français généré via Google TTS, normalisé et amplifié (+12 dB) pour le haut-parleur des robots aspirateurs Dreame (notamment le Dreame L10s Ultra et modèles similaires sous Valetudo).

## 🚀 Installation rapide via Valetudo

1. Rendez-vous dans l'interface Valetudo : **Robot Settings** -> **Misc Settings** -> **Voice Pack Settings**.
2. Remplissez les champs :
   - **URL :** `[https://github.com/solidkris/Dreame_L10S_ultra_voicepack/blob/main/voicepack_fr.tar.gz]`
   - **Language Code :** `fr`
   - **MD5 Hash :** *ba2182ca035b16f9b105515387b6c8fe*
3. Cliquez sur **Set Voice Pack**.
